# Methods

## Task and data

The task is the prediction of propeptide cleavage sites in precursor protein
sequences: given an amino acid sequence, identify the coordinate spans
corresponding to propeptide regions. Following Teufel et al. (2023), this is
framed as sequence labelling with a conditional random field over a
duration-encoded state grammar rather than as per-residue classification, so that
the model emits contiguous spans of admissible length directly.

The dataset is the UniProt-2022 benchmark distributed with DeepPeptide. It
comprises 14,583 records which deduplicate to 8,061 unique sequences. Sequences
are assigned to five homology-reduced partitions by Graph-Part (Teufel et al.),
which enforces a maximum sequence identity between partitions and so prevents
homologues of test sequences appearing in training. Partitions 0, 1 and 2 were
used for training (4,455 sequences), partition 3 for validation and model
selection (1,630), and partition 4 as a held-out test set (1,538). No sequence
from partition 4 was inspected at any point during model development.

The original DeepPeptide model predicts mature peptides and propeptides jointly
using a 3-label, 101-state formulation. The present work restricts the task to
propeptides alone, giving a 2-label, 51-state model in which state 0 denotes
background and states 1–50 encode position within a propeptide of length between
5 and 50 residues. Mature-peptide annotations were discarded.

## Architecture

The predictor is unchanged from Teufel et al. Per-residue embeddings are passed
through a feature extractor consisting of 2-D feature dropout, a 1-D convolution,
a ReLU nonlinearity, a bidirectional LSTM and a second convolution; a linear layer
projects to state emissions, and a linear-chain CRF with the duration-encoded
transition structure produces the final labelling by Viterbi decoding. Optimisation
uses Adam at a constant learning rate with no schedule, and the checkpoint retained
is the one achieving the highest validation propeptide F1.

Only one component of this pipeline varies across experimental arms: the frozen
embedding supplied as input. The embedding model itself is never updated in the
frozen experiments; representations are extracted once, cached to disk as one
tensor per sequence keyed by the MD5 hash of the sequence, and read from disk
during training.

## Representations compared

Four input representations were evaluated:

| representation | model | dimension |
|---|---|---|
| ESM-2 | `esm2_t33_650M_UR50D`, final layer | 1280 |
| ESM3 | `esm3_sm_open_v1`, sequence track only, final layer | 1536 |
| ProstT5 | encoder with the `<AA2fold>` prefix | 1024 |
| one-hot | 20 canonical amino acids plus a catch-all column | 21 |

The one-hot arm is a control in the sense of Hewitt and Liang (2019). The
prediction head used here is not a linear probe: its convolutional and recurrent
layers carry sufficient capacity to learn a substantial part of the task from
residue identity alone. A difference between two pretrained representations is
therefore only interpretable relative to the performance obtainable with no
pretrained information at all, which the one-hot arm establishes.

Each embedding set was verified before use with an acceptance test checking
coverage against the dataset hashes, tensor shape against sequence length, dtype,
finiteness, absence of all-zero rows, dimension, and the mean per-residue L2 norm.
This last check is not incidental. ESM3's `ESMOutput.embeddings` field exposes the
raw pre-LayerNorm residual stream rather than the normalised tensor its own output
heads consume, and its per-residue norm is roughly three orders of magnitude larger
than that of the ESM-2 representations the pipeline was designed around. Feeding it
unnormalised saturates the recurrent layer at initialisation. The extractor applies
the model's final LayerNorm explicitly; the verified ESM3 embeddings have a mean
per-residue norm of 11.023, consistent with the post-normalisation range.

A second extraction issue is recorded for completeness. ESM3's geometric attention
block executes unconditionally, including when no structural input is supplied, and
materialises a tensor quadratic in sequence length that exceeds the memory of a
32 GB accelerator for the longest sequences in this dataset. Disabling the block
for sequence-only extraction was verified to leave the output bit-identical
(maximum absolute difference 0.0 across all embedding dimensions), so it is a
computational saving and not a modification of the model under evaluation.

ESM3 is released with bfloat16 weights and has no float32 release; it was therefore
run in its native precision, while ESM-2 and ProstT5 were run in float32. All
representations were stored on disk as float32.

## Training and hyperparameter protocol

Per-representation hyperparameter optimisation was not computationally feasible.
Two configurations were therefore used, and the distinction between them is
important to the interpretation of the results.

The first is the configuration reported as T4 by Teufel et al., which those authors
selected for ESM-1b and ESM-2 (learning rate 0.0055, batch size 20, input dropout
0.6902). Applying it unchanged to another representation constitutes a controlled
swap in which every element of the pipeline is held fixed and only the input
changes, but at a setting chosen for one particular arm.

The second is the framework's untuned default (learning rate 1e-4, batch size 100,
input dropout 0.1, 50 epochs), which was selected for none of the representations
in the comparison. Early stopping was disabled for these runs so that every arm
received an identical epoch budget; with early stopping active, an arm which
improves continues training while an arm which stalls is terminated, and the
stopping rule rather than the representation determines the effective budget.

ESM3 additionally has results at a configuration identified by an in-house sweep
(learning rate 5e-4, batch size 70). Because that sweep compared test-set F1, any
number derived from it is optimistically biased, and this is noted wherever it is
used.

## Evaluation metric

Performance is reported as segment-level propeptide F1 at a boundary tolerance of
±3 residues, micro-averaged over the test partition. A predicted span counts as a
true positive only if both its start and its end fall within the tolerance of a
true span's corresponding boundaries; overlapping true annotations are grouped and
contribute at most one count. True positives, false negatives and false positives
are accumulated across all proteins before precision, recall and F1 are computed.

This is a demanding criterion and is not comparable with per-residue F1 reported by
other peptide predictors: a span with a correct start and an end four residues late
scores as one false positive and one false negative. It is nonetheless the
appropriate criterion here, since propeptide boundaries correspond to protease
cleavage sites.

Two defects in the reference implementation of this metric were corrected. First,
the matching routine reused a single loop variable across the iteration over true
spans and the iteration over predicted spans, recording a matched true span at the
predicted span's index; the resulting row is discarded by the subsequent grouping
operation, converting true positives into false negatives. The effect is not a
constant offset — it is larger for models emitting more false positives — so it
distorts comparisons between models rather than merely shifting them. Second, the
recall computation was guarded by the wrong denominator. All results reported here
use the corrected metric; figures reproducing the published DeepPeptide numbers are
kept on a separate branch under the original implementation and are not tabulated
alongside.

## Statistical analysis

Single training runs are not treated as measurements. Each configuration was run
repeatedly and is reported as a distribution.

Replicate runs are unseeded. The training entry point used for these experiments
does not call `torch.manual_seed`, so runs differ in parameter initialisation, data
ordering and accumulated floating-point nondeterminism simultaneously. This is the
whole-pipeline variation that Bouthillier et al. (2021) argue a replicate should
capture, and Summers and Dinneen (2021) report that individual sources of
nondeterminism have comparable effects on model diversity, with one-bit changes to
initial parameters sufficient to produce substantially different converged models.

Groups are formed by the complete recorded configuration excluding the output
directory and seed, so two runs are pooled only when every other field is identical.
Pooling across a hyperparameter that was itself selected on validation data would
treat a tuning decision as replicate noise and inflate the effective sample size.

Comparisons use Welch's unequal-variance t-test with Welch–Satterthwaite degrees of
freedom, two-sided. Alongside each mean, a 95% prediction interval for one further
run of the same configuration is reported as
mean ± t(n−1, 0.975) · sd · √(1 + 1/n). This quantity is the appropriate reference
for any result obtained from a single run, and several published-style comparisons
in the exploratory sweep fall entirely inside it.

# Results

## Primary comparison

Each representation was evaluated at the best configuration available to it, with
at least five replicate runs per arm.

| representation | configuration | n | mean F1 | sd | min | max |
|---|---|---|---|---|---|---|
| ESM-2 | T4 | 10 | 0.6153 | 0.0242 | 0.5772 | 0.6510 |
| ESM3 | lr 5e-4, batch 70 | 15 | 0.5203 | 0.0185 | 0.4881 | 0.5445 |
| ProstT5 | T4 | 5 | 0.5189 | 0.0306 | 0.4717 | 0.5436 |

| comparison | difference | t | df | p |
|---|---|---|---|---|
| ESM-2 vs ESM3 | 0.0949 | 10.531 | 15.81 | 1.5 × 10⁻⁸ |
| ESM-2 vs ProstT5 | 0.0964 | 6.141 | 6.60 | 5.9 × 10⁻⁴ |
| ESM3 vs ProstT5 | 0.0014 | 0.098 | 5.01 | 0.926 |

ESM-2 outperformed both alternatives by approximately 0.095 F1. ESM3 and ProstT5
were statistically indistinguishable.

These comparisons carry different weight because the arms did not receive equal
tuning, and the direction of the resulting bias differs between them.

The comparison between ESM-2 and ESM3 is conservative. ESM3's configuration was
selected by comparing test-set F1 across an exploratory sweep, so its mean is
optimistically biased relative to a properly held-out estimate, and it was
nonetheless outperformed by a margin far larger than the run-to-run variation of
either arm. The conclusion that ESM3 does not improve on ESM-2 for this task is
therefore robust to the tuning asymmetry, since correcting the asymmetry would move
the estimate in the direction that strengthens it.

The comparison between ESM-2 and ProstT5 is not conservative in the same way. It is
a strict controlled swap — the two groups are identical in every recorded
configuration field, which is enforced by the grouping procedure rather than
assumed — but the shared configuration is ESM-2's. The result establishes that
ProstT5 performs worse *at ESM-2's hyperparameters*, which bounds its deficit from
above; it does not establish that ProstT5 is an inferior representation for this
task.

The absence of a detectable difference between ESM3 and ProstT5 is consistent with
a broader pattern in empirical machine learning. Lucic et al. (2018) found that
architectures separated by substantial claimed improvements converged to similar
performance once each was given comparable hyperparameter search and multiple
restarts, and attributed apparent differences to computational budget rather than
to method.

## Behaviour at untuned defaults

All four representations, including the control, were additionally trained at the
framework's default configuration with five replicates each and identical epoch
budgets.

| arm | n | mean F1 | sd | min | max |
|---|---|---|---|---|---|
| ESM-2 | 5 | 0.5079 | 0.0714 | 0.3853 | 0.5682 |
| ProstT5 | 5 | 0.4091 | 0.1094 | 0.2210 | 0.4974 |
| ESM3 | 5 | 0.2335 | 0.1930 | 0.0440 | 0.4438 |
| one-hot | 5 | 0.2308 | 0.0901 | 0.0802 | 0.3073 |

This experiment does not rank the representations, and is not presented as doing
so. Two observations establish why.

First, no arm converged within the epoch budget. Examining the validation curves,
17 of 19 completed runs attained their best validation F1 within the final ten of
fifty epochs, indicating that training terminated while the models were still
improving.

Second, the ESM3 arm is bimodal rather than merely variable. Two of its five seeds
reached best validation F1 of 0.6111 and 0.6159; the remaining three reached 0.1017,
0.1423 and 0.0451. A standard deviation of 0.1930 summarises a bifurcation between
runs that trained and runs that did not, and a mean computed across it is not a
meaningful central tendency. The apparent equivalence of ESM3 and the one-hot
control under this configuration (difference 0.0027, p = 0.978) accordingly reflects
optimisation failure and carries no implication about the information content of
ESM3 embeddings.

What this experiment does support is a statement about optimisation robustness, and
it is specific to ESM3: at the framework's default hyperparameters, ESM-2 trained
successfully on five seeds of five and ProstT5 on the majority, while ESM3 failed to
depart from a degenerate all-negative solution on three of five. ProstT5's mean rose
as its final replicates completed, confirming that the instability is not a general
property of the non-ESM-2 arms.

This outcome also identifies a limitation of the experimental design itself.
Equalising the *configuration* across arms does not equalise the *treatment*: a
shared setting leaves different representations at different points on their
optimisation trajectories within a fixed budget. Equal-budget comparison, in the
sense advocated by Musgrave et al. (2020) and Dodge et al. (2019), requires equal
tuning per arm rather than an identical untuned configuration.

## Parameter-efficient fine-tuning

Low-rank adaptation of the ESM3 backbone was evaluated against the frozen setting.
This arm is restricted to ESM3 by the implementation, which instantiates the ESM3
model class directly; no corresponding result exists for ESM-2 or ProstT5, and
nothing here generalises to them.

| configuration | n | mean F1 | sd | mean validation F1 |
|---|---|---|---|---|
| LoRA, lr 3e-4 | 1 | 0.5972 | — | 0.7209 |
| LoRA, lr 1e-4 | 4 | 0.5759 | 0.0577 | 0.7159 |
| LoRA, lr 5e-5 | 4 | 0.5634 | 0.0613 | 0.6998 |
| frozen control | 1 | 0.5316 | — | 0.6590 |

Neither LoRA group separated from frozen ESM-2 (differences 0.0394 and 0.0519,
p = 0.268 and p = 0.188), nor from frozen ESM3. The limiting factor is variance:
at standard deviations of 0.0577 and 0.0613 these are the most variable replicate
groups in the study, approximately 2.5 times the spread of the frozen ESM-2 arm.
Each group contains one seed that collapsed, and in both cases validation F1 fell
for that seed as well, indicating that validation-based screening would have
identified them.

Schmirler et al. (2024) report that task-specific fine-tuning improves downstream
prediction in almost all of the eight tasks they examine. That is not reproduced
here. The appropriate conclusion is that this study, at n = 4 against n = 10, lacks
the power to resolve a difference of the magnitude observed — not that fine-tuning
is ineffective.

## Structure conditioning

ESM3 accepts structural input alongside sequence. At matched configuration, adding
the structure track reduced performance:

| input | F1 | precision | recall |
|---|---|---|---|
| sequence only | 0.5280 | 0.7179 | 0.4176 |
| sequence + structure | 0.4712 | 0.7269 | 0.3486 |

The difference of 0.0568 is located almost entirely in recall. Both are single runs,
and the narrowest well-estimated prediction interval in this study is ±0.0409, so
this observation sits only marginally outside what one run per condition can
resolve. It is suggestive rather than established. Two further structure-conditioned
runs at other learning rates fall lower still, which is consistent, but they are
likewise unreplicated.

## Run-to-run variation

95% prediction intervals for one further run of the same configuration:

| group | n | interval |
|---|---|---|
| ESM3 frozen, tuned | 15 | ±0.0409 |
| ESM-2 frozen, T4 | 10 | ±0.0574 |
| ProstT5 frozen, T4 | 5 | ±0.0931 |
| LoRA, lr 1e-4 | 4 | ±0.2053 |
| ESM-2, default configuration | 5 | ±0.2171 |
| ProstT5, default configuration | 5 | ±0.3326 |
| ESM3, default configuration | 5 | ±0.5871 |

These intervals have a direct consequence for how the exploratory sweep should be
read. That sweep contains 28 singly-run configurations spanning F1 from 0.4388 to
0.5547, a range of 0.116, against a ±0.0409 interval derived from the
best-estimated group. Most pairwise differences within it are smaller than the
noise. Two learning-rate settings differing by 0.0100 in test F1, for instance,
differ by roughly a quarter of the prediction interval, and no conclusion about
which is preferable follows from those runs.

# Discussion

The hypothesis motivating this work was that ESM3, as a newer and larger model
incorporating structural and functional training signal, would yield better frozen
representations for propeptide prediction than ESM-2. That hypothesis is not
supported. ESM-2 outperformed ESM3 by 0.0949 F1 under a comparison that was biased
in ESM3's favour, and ESM3 was indistinguishable from ProstT5, an older
sequence-and-structure model of smaller size.

This is consistent with published findings. Vieira et al. report that larger protein
language models do not consistently outperform smaller ones, particularly when
training data is limited, and identify medium-sized models as offering the best
balance of performance and cost. Schmirler et al. find that the relative ranking of
protein language models varies across downstream tasks. The present result adds one
task to that picture rather than contradicting a consensus.

Three limitations bound the conclusions.

The comparison rests on a single homology-partitioned split rather than
cross-validation, so the estimates are conditional on which partition was held out.
The framework implements nested cross-validation and this would be the most valuable
extension, at five times the computational cost.

The arms received unequal hyperparameter tuning. The direction of the resulting bias
is known for each comparison and is stated with each result, but only per-arm search
under an equal budget would remove the confound.

The prediction head's parameter count depends on the input dimension through its
first convolution, so arms differ slightly in capacity. The effect runs against the
lower-dimensional representations, and so cannot manufacture the observed advantage
for ESM-2; it does mean that the one-hot control's weaker performance cannot be
attributed entirely to the absence of pretraining, since its head is also the
smallest.

For the applied question — which representation to use for propeptide prediction —
the recommendation is ESM-2. It achieved the highest F1, by a margin exceeding the
run-to-run variation of any arm; it trained reliably where ESM3 did not; and it is
the least expensive of the three in parameters, embedding dimension, storage and
training time.
