# torch: THIS BRANCH IS GPU-ONLY, so you need a CUDA build. A plain
# `pip install torch` can resolve to a CPU-only wheel depending on the index and
# platform (our CPU node ended up with 2.2.0+cpu), and the run will refuse to
# start. Verify after installing:
#
#     python -c "import torch; print(torch.__version__, torch.version.cuda)"
#
# If that prints cuda=None, reinstall from the CUDA index, matching the driver
# on the machine, e.g. for CUDA 12.1:
#
#     pip install --index-url https://download.pytorch.org/whl/cu121 torch
#

# pandas: any 2.x or 3.x works. 2.x prints a FutureWarning about downcasting on
# .fillna, which src/utils/dataset.py filters — verified inert (the frame is
# identical under pandas 3.0, which is the behaviour being warned about). See the
# comment there before "fixing" it; the obvious rewrites either do not silence it
# or change dtypes and values.

# optuna is required by preflight.py as well as by the search: preflight inspects
# any study already present in --out_dir, because resuming a finished one runs
# zero new trials and silently returns stale hyperparameters.
